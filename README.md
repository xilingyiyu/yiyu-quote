# 一言语录 (Yiyu Quote)

> 运行在小米 Vela 手表上的语录应用 —— 双接口取句、离线缓存、轻量小巧

## 预览

![Logo](src/common/icon.png)

## 功能特性

- 🗣 **双数据源**：一言（hitokoto）+ uapis 网络语录两个接口
- 🌐 **联网双取**：每次取句时两个接口并行各调用一次，随机展示一个，**两个结果都入缓存**（一次 +2 条）
- 💾 **离线缓存兜底**：断网时从本地缓存随机展示；**每消费 2 条缓存，自动后台试调一次一言接口**——网络恢复即补 1 条新句进缓存
- 🔢 **预存条数可调**：联网时预存条数 1-50 可调（手表数字键盘输入）
- ⌨️ **键盘输入**：可手动输入自定义语录
- ⚡ **轻量**：单包 < 60KB

## 技术栈

| 项目 | 说明 |
|---|---|
| 运行平台 | Xiaomi Vela OS（快应用） |
| 语言 | JavaScript（ES5，Vela 引擎） |
| 构建 | aiot-toolkit（官方打包器，自动签名） |
| 数据源 | `https://v1.hitokoto.cn/?encode=json&max_len=42`（一言）<br>`https://uapis.cn/api/v1/saying`（uapis） |
| 目标设备 | Redmi Watch 5（336dp 设计稿，px 自适应） |

## 构建

### 环境要求

- Node.js ≥ 16
- `@aiot-toolkit/aiotpack`（项目依赖）

### 打包

```bash
npm install
node_modules/.bin/aiot build
```

产物输出到 `dist/com.yiyun.quote.debug.<版本>.rpk`（官方工具链自动签名）。

> ⚠️ 每次修改后在 `src/manifest.json` 中递增 `versionCode`（建议 +1）。

## 安装

1. 下载 [AstroBox](https://abox.run)（手机/电脑均可）
2. 蓝牙连接手表 → 导入 `.rpk` 安装
3. 打开应用：**点按换一句**，**左滑进入设置菜单**

> 已知问题：部分情况下安装进度条卡在最后一步（设备端偶发），**手表重启后重试**即可。

## 缓存设计

| 项 | 说明 |
|---|---|
| 存储 key | `q_cache`（JSON 数组，元素 `{t: 正文, f: 出处, s: 来源}`） |
| 预存上限 | `maxCount`（默认 10，可调 1-50，key: `q_max`） |
| 联网行为 | 每次两个接口各调一次，结果全部入缓存（+2 条/次），超出上限淘汰最旧 |
| 离线行为 | 随机取 1 条缓存展示并移除；每消费 2 条尝试联网补 1 条一言新句 |
